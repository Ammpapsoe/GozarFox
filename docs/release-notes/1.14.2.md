# Gozar 1.14.2

## فارسی

- ورود مستقیم با ایمیل و رمز عبور در اندروید، دقیقاً مانند نسخه‌ی ویندوز: اطلاعات مستقیم به هسته می‌رود، چالش لبه همان‌جا حل می‌شود و نیازی به مرورگر نیست.
- صفحه‌ی ورود حالا دو تب دارد: «ورود با ایمیل و رمز» و «ورود با مرورگر»؛ ورود با WebView دست‌نخورده و مثل قبل کار می‌کند.
- رفع باگ کد تأیید دو مرحله‌ای در WebView: وقتی موزیلا کد می‌خواهد، صفحه باز و منتظر می‌ماند و اگر صفحه کد را برنگرداند، کادر وارد کردن کد به‌صورت بومی نمایش داده می‌شود.
- رفع باگ افزودن حساب دوم: کارت موفقیتِ بی‌موقع حذف شد؛ WebView برای حساب جدید با کوکی‌های پاک‌شده از صفر باز می‌شود.
- حذف هدر و اسپینر از صفحه‌ی WebView: صفحه تمام‌صفحه است و فقط دکمه‌ی «بازگشت» روی آن شناور است.
- پیام‌های خطای ورود به فارسی.

## English

- Direct email + password sign-in on Android, exactly like the desktop app: credentials go straight to the core, the edge challenge is solved there, and no browser is involved.
- The sign-in screen now has two tabs: "Email & password" and "Browser sign-in"; the working WebView path is untouched.
- Fixed the two-factor code bug in the WebView: when Mozilla asks for a confirmation code the screen stays open and waits, and if the page never re-announces the session, a native code box finishes the sign-in.
- Fixed the second-account bug: the premature success card is gone; the WebView for a new account starts cold with its cookies wiped.
- The WebView screen lost its header and spinner: the page is full screen with only a floating Back pill.
- Sign-in error messages in Persian.
