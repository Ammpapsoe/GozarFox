## Gozar 1.11.3 — integrated tunnel hardening (draft)

This candidate integrates tunnel lifecycle, DNS, sign-in and signed-update
hardening on Android and desktop. It is not yet a validated stable release.

### Changes

- Adds an IPv4 UDP packet path through authenticated HTTP/2 CONNECT-UDP and
  DATAGRAM capsules on Android and desktop. DNS retains its existing path.
  Unsupported or refused UDP is not silently sent directly. Relay compatibility
  and actual UDP delivery with a production account remain **unverified**.
- Improves cleanup of pending and established tunnel connections during reset,
  reconnect and service replacement. Android DNS attempts and UDP flows are
  scoped to their tunnel generation. Diagnostic counters describe the app's
  tunnel only; they do not prove device-wide leak protection.
- Improves retry and lifecycle handling for sign-in, logout and overlapping
  operations. An authorized account test still stopped at HTTP 406 during
  OAuth; no real relay session was established. See `docs/real-account-validation.md`.
- Retains signed Android updates and signed desktop update downloads. Desktop
  installation remains a user action.

### Validation and limitations

Automated tests include synthetic packet/proxy paths, concurrency stresses,
release build and signed-upgrade emulator checks. Native desktop TUN tests use
local simulated proxies, not production relays. Android IPv6 and fragmented
packets remain fail-closed. Capsule confirmation and the default relay URI are
strict compatibility assumptions; some relays may reject the new UDP path.
No claim is made about all devices, networks, game ports, data usage, latency or
device-wide leak freedom. A successful installation of an older release is not
proof of UDP support in this candidate.

An authenticated production UDP round trip and final exact-commit build and
upgrade checks remain necessary before a stable release can be represented as
validated.
