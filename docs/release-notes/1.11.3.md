## Gozar 1.11.3 — tunnel and update hardening (draft)

This candidate is not yet a validated stable release.

### Changes

- Adds opt-in IPv4 UDP through Cloudflare WARP CONNECT-IP inside the
  authenticated Mozilla tunnel on Android and desktop. Enabling it requires
  acceptance of Cloudflare's application terms and registers a free WARP
  device. The client automatically scans endpoints and selects one only after
  a real authenticated UDP response; unavailable UDP does not silently fall
  back to Mozilla CONNECT-UDP or a direct UDP socket.
- Keeps DNS on its existing tunnelled resolver path. Android routes captured
  IPv6 into the VPN for dropping. Desktop is IPv4-only: existing LAN, relay
  and IPv6 routes can be outside its tunnel, including UDP, as disclosed in
  the setting. Selective direct routing is paused while desktop WARP is on.
- Improves sign-in and token-refresh handling, tunnel cancellation, reconnect
  and DNS lifecycle. Signed Android updates and signed desktop download checks
  remain in place; desktop installation is still a user action.

### Validation and limitations

A user-authorized real-account script authenticated with Mozilla, refreshed a
token and reached a real relay. CI-built Kotlin and Go WARP cores each passed
an authenticated UDP round trip through a restricted bridge to that Mozilla
relay; Kotlin also re-enrolled the same test device through it. These do not
prove the complete Android or desktop application on a physical device.
Automated tests use simulated services; exact-commit build,
native TUN and signed-upgrade emulator results must be checked separately.

WARP carries IPv4 only, drops fragmented or oversized packets, and runs HTTP/2
over TCP, so performance and every destination port are not guaranteed. Android
7–9 depend on a non-public ALPN compatibility path that may be unavailable and
has not been verified on a physical device. No
claim is made of device-wide leak freedom, all-network compatibility, or
physical-device validation.
