## Gozar 1.12.0-rc.4 — چرخهٔ رسمی Orbot و ورود Material 3

**این نسخه Prerelease است، نه Stable.** اعتبارسنجی GitHub Actions روی emulator انجام می‌شود و به‌هیچ‌وجه به معنی موفقیت روی دستگاه فیزیکی همراه اول یا ایرانسل نیست.

### Tor و Bridge

- موتور handwritten قبلی حذف شده و اتصال با `TorService` و `TorControlConnection` رسمی Guardian Project، مالکیت bind/unbind، start-request guard و مدیریت binding death بر اساس Orbot انجام می‌شود. Orbot برای اجرا لازم نیست.
- Tor در process اختصاصی `:tor` باقی می‌ماند و process اصلی از Control Socket رسمی Tor استفاده می‌کند. مرگ Tor باعث آزادسازی تونل مرده و تلاش بعدی تازه می‌شود؛ تونل سالم ۱۰۰٪ همچنان برای خطاهای Mozilla حفظ می‌شود.
- Bridge دستی obfs4 با certificate استاندارد ۷۰ کاراکتری پذیرفته می‌شود. اعتبارسنجی آدرس، جلوگیری از injection، normalize کردن whitespace، محافظت signed feed و نگهداری Bridge فقط در RAM حفظ شده است.
- Transport و Bridge ابتدا با SETCONF اعمال و سپس `DisableNetwork=0` فعال می‌شود. Stop و Logout سرویس، transport و listenerهای متعلق به login را آزاد می‌کنند.

### رابط ورود و گزارش امن

- صفحهٔ ورود با Material Design 3، فیلدهای outlined، کارت، فاصله‌گذاری و سلسله‌مراتب تازه بازطراحی شده و تصویر پس‌زمینهٔ Firefox حفظ شده است.
- دکمهٔ بزرگ outlined Stop دقیقاً زیر Login و بدون هم‌پوشانی قرار دارد.
- Log Viewer بالای صفحهٔ ورود فقط رویدادهای وضعیت و تشخیص sanitize‌شده را در RAM نشان می‌دهد؛ Bridge، IP، fingerprint، certificate، credential و token نمایش داده نمی‌شود.
- از Nathan Freitas، The Guardian Project و مشارکت‌کنندگان Orbot تشکر می‌شود. اطلاعات attribution و BSD 3-Clause notice در مخزن و APK نگهداری می‌شود.

### بسته‌ها و انتشار

- APKهای universal، arm64-v8a، armeabi-v7a، x86 و x86_64 ارائه می‌شوند. IPtProxy 5.8.0 برای هر چهار ABI از source یکسان و با `android/386` برای x86 ساخته می‌شود؛ جایگزین native ناسازگار مجاز نیست.
- انتشار شامل `SHA256SUMS` و امضای آن است و Gate دقیقاً ۷۱ asset، امضاها، هش‌ها و identity رسمی Android را بررسی می‌کند.
- انتشار عمومی فقط پس از موفقیت same-commit compile، unit/UI/security tests، native lifecycle روی x86_64 و x86 و real-account emulator validation انجام می‌شود.

## English

Gozar 1.12.0-rc.4 replaces the previous handwritten Tor lifecycle with the official Guardian Project TorService/control architecture adapted from Orbot, while keeping Tor in its dedicated process and retaining healthy 100% tunnels across Mozilla retries. Manual obfs4 input remains RAM-only and the reported 70-character certificate format is covered at the LoginActivity boundary.

The Material 3 login retains the Firefox artwork, adds a large non-overlapping Stop button, and provides a RAM-only sanitized Tor event viewer. Guardian Project and Orbot attribution and the BSD 3-Clause notice are included.

Universal and four ABI-specific Android packages are built from matching native sources, including an IPtProxy 5.8.0 x86 build using android/386. The signed draft-first release gate requires all 71 assets, checksums, signatures, and exact-commit emulator evidence. Emulator results are not physical-device or Iranian-ISP validation.
