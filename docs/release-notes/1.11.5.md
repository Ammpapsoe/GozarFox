## Gozar 1.11.5 — اصلاح ورود با Tor و چرخهٔ حیات native

**نسخه‌های قبلی به‌دلیل مشکلات موجود حذف شده‌اند و دیگر منتشر یا پشتیبانی نمی‌شوند. تمرکز توسعه و اعتبارسنجی روی همین نسخهٔ جدید است.**

### اصلاحات

- کرشهای restart کتابخانهٔ native تور و خطای `trackGoRef` در IPtProxy اصلاح شده‌اند. Tor در process اختصاصی اجرا می‌شود، پیش از retry کاملاً متوقف می‌شود و initialization مشترک IPtProxy بین Snowflake و Meek حفظ می‌شود.
- پوشه و فایلهای Tor قبل از هر تلاش تازه ساخته و پاک‌سازی می‌شوند. هر Login یا Signup تازه، خطاها و وضعیت authentication قبلی را حذف می‌کند.
- مسیر خودکار Direct، Snowflake و Meek با مهلت ۹۰ ثانیه، نمایش درصد bootstrap، مرحله و خطاهای sanitize‌شده انجام می‌شود.
- ترافیک حساب تا bootstrap کامل ۱۰۰٪ گیت است؛ پس از احراز هویت Tor متوقف و Mozilla tunnel مستقیم برقرار می‌شود.

### نتایج واقعی اعتبارسنجی

- دو چرخهٔ کامل native تور روی **emulator روت‌شدهٔ GitHub Actions با SELinux آزمایشی Permissive** موفق بوده‌اند. Root فقط برای محیط تست است و قابلیت اپلیکیشن نیست.
- حساب موجود دو بار پشت‌سرهم وارد شد، Mozilla pass دریافت کرد و direct Mozilla tunnel برقرار و متوقف کرد: `LOGIN_PASS_AND_DIRECT_TUNNEL_TWICE_OK`.
- ثبت‌نام تا دریافت درخواست کد ایمیل Mozilla پیش رفت: `SIGNUP_CODE_DELIVERY_OK`. کاربر کد را در برنامه وارد می‌کند؛ verify نهایی با کد واقعی در این اعتبارسنجی انجام نشده است.
- Test، Autonomous compile/unit tests و native validation روی commit انتشار اجرا می‌شوند.

### محدودیت شفاف

این نتایج تست گوشی فیزیکی نیستند. نصب و تست نهایی روی گوشی کاربر هنوز جداگانه لازم است و موفقیت emulator به معنی اثبات عملکرد روی همهٔ دستگاه‌ها یا شبکه‌های ایران نیست.

## English

Previous versions have been removed because of their existing issues and are no longer published or supported. Development and validation now focus on this new version.

This release fixes the identified native Tor restart crashes, IPtProxy `trackGoRef` lifecycle failure, stale login state and missing Tor directory recreation. Two complete native Tor lifecycles passed on the rooted GitHub Actions emulator with test-only permissive SELinux.

The existing test account completed two full login, Mozilla pass, direct Mozilla tunnel and stop/clear cycles. Signup reached Mozilla's email-code step successfully; final code verification was not part of this validation and the user can enter the code in the app.

These results do not claim physical-device or Iranian-ISP validation. Final installation and testing on the user's phone remain necessary.
