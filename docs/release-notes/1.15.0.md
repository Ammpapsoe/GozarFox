# Gozar 1.15.0

## فارسی

- صفحه‌ی اصلی دسکتاپ (ویندوز/مک/لینوکس) با الهام از چیدمان و رنگ‌بندی کلاینت متن‌باز Windscribe بازطراحی شد: صحنه‌ی سرمه‌ای، دکمه‌ی بزرگ دایره‌ای اتصال با حلقه‌ی نورانی، حباب مکان‌ها در پایین و نشان سپر Kill Switch بالا. (منطق اتصال کاملاً متعلق به Gozar است؛ پروانه‌ی GPL-2.0 منبع الهام در README ذکر شده.)
- کلید قطع اضطراری (Kill Switch) در ویندوز دیگر به‌صورت پیش‌فرض روشن نیست؛ از تنظیمات دسکتاپ روشن می‌شود و خطای «filename or extension is too long» هم برطرف شد (دستورات PowerShell از طریق فایل موقت اجرا می‌شوند).
- تب‌های صفحه‌ی ورود اندروید دیگر متن را نمی‌برند؛ دکمه‌ی Logs کاملاً حذف شد.
- در تب مرورگر اندروید، هشدار فارسی درباره‌ی نیاز احتمالی به فیلترشکن نمایش داده می‌شود.

## English

- The desktop connect screen (Windows/macOS/Linux) is redesigned in the idiom of the open-source Windscribe desktop client: navy stage, one large ringed connect button, a locations bubble along the bottom and a kill-switch shield badge on top. Appearance only — the connection logic is entirely Gozar's; the GPL-2.0 source of inspiration is credited in the README.
- The Windows kill switch is no longer on by default; it is opt-in from desktop settings, and the "filename or extension is too long" failure is fixed by running the PowerShell rules from a temporary script file.
- The Android sign-in tabs size themselves to their text instead of clipping it, and the Logs button is gone for good.
- The Android browser tab shows a Persian warning that this path may briefly need a filter.
