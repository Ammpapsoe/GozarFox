## Gozar 1.11.1 — Android signed-update hardening (draft)

- Android verifies the Ed25519 manifest before deciding whether an update is current or available. Downloads are restricted to signed size, digest, version and release-asset paths.
- An installer handoff is not treated as a completed installation. Android normally will not replace an installed APK with an older version, so the recovery notice checks for a **newer signed update** instead of claiming that an old cached APK can be restored.
- Update-trial state is stored with atomic replacement and protected against concurrent journal instances. Unconfirmed launches do not by themselves prove a crash.

**Not ready for publication:** the desktop branch verifies and downloads signed platform packages, but installation is still manual. Complete cross-platform recovery, a tested forward-recovery build and device-level end-to-end validation remain outstanding.
