## Gozar 1.11.1 — پیش‌نسخهٔ آزمایشی / Preview

**این انتشار نهایی نیست.** این نسخه برای آزمایش عمومی تغییرات فعلی منتشر شده است؛ نسخهٔ پایدار قبلی همچنان نسخهٔ پیش‌فرض GitHub است. کامل‌شدن همهٔ فازهای پروژه ادعا نمی‌شود.

### تغییرات

- مدیریت نشست‌های HTTP/2 و صف بسته‌ها در بخش اندروید بازنگری شده و آزمون‌های رقابتی آن گسترش یافته‌اند.
- اندروید پیش از پذیرش به‌روزرسانی، امضای Ed25519 فراداده را بررسی می‌کند و هنگام دریافت APK اندازه و هش امضاشده را کنترل می‌کند.
- دسکتاپ فرادادهٔ امضاشده و فایل بستهٔ متناسب با سیستم را بررسی و دریافت می‌کند. **نصب بسته در دسکتاپ هنوز دستی است؛ بازگشت خودکار وجود ندارد.**
- در اندروید، به‌جای وعدهٔ نصب نسخهٔ قدیمی، اعلان بازیابی پیشنهاد می‌کند نسخهٔ امضاشدهٔ جدیدتر بررسی شود. نداشتن اتصال تأییدشده به‌تنهایی نشانهٔ خرابی برنامه نیست.

### محدودیت‌های مهم

- بازیابی خودکار در زمان اجرا‌نشدن برنامه، سازگاری همهٔ مهاجرت‌های داده و بازگردانی کامل روی همهٔ سکوها هنوز تکمیل یا اثبات نشده است. نصب Android به تأیید کاربر و سیاست دستگاه وابسته است.
- آزمون‌های شبیه‌ساز و CI جایگزین آزمون روی همهٔ دستگاه‌های واقعی یا شرایط شبکهٔ ایران نیستند. ارقام کمتر از ۱ مگابایت در روز، کمتر از ۵۰۰ میلی‌ثانیه، اتصال بالای ۹۵٪ و نبود مطلق نشت در این انتشار تأیید نمی‌شوند.
- این پیش‌نسخه در فهرست `latest` گیت‌هاب قرار نمی‌گیرد؛ برای آزمایش باید فایل مناسب دستگاه را از همین صفحه به‌صورت دستی دریافت کنید.

### English summary

This is an **incomplete preview**, not the final eight-phase release. Android verifies signed update metadata and APK hashes; desktop can verify and download packages but does not install or automatically roll them back. Full cross-platform recovery, arbitrary data migrations, real-world Iran connectivity and device-wide leak freedom remain unverified. This prerelease is not offered as GitHub's latest stable release.
