# Gozar 1.17.0

## فارسی

- **هسته‌ی تانل Native:** موتور بسته‌ای دست‌ساز قبلی بازنشسته شد؛ «hev-socks5-tunnel 2.20.0» (lwIP لوشن‌شده، NDK r27) حالا دستگاه TUN و همه‌ی جریان‌های TCP و UDP را می‌بندد. وقتی تانل یا رله در دسترس نباشد، هیچ بسته‌ای مستقیم خارج نمی‌شود — شکست بسته‌ها بی‌صدا و fail-closed است.
- **DNS بی‌خطر می‌ماند:** پرسش‌های پورت ۵۳ محلی و با داوری سریع DoH (DoH race) با پروفایل‌های سفارشی، BlockAds، وصله‌ی TTL و ضدسم‌پاشی سرو می‌شوند؛ همه‌ی این رفتارها به صفحه کنترل «FoxDnsBridge» منتقل شد و پاسخ‌های متعلق به تلاشِ قدیمی هرگز منتشر یا یاد گرفته نمی‌شوند (epoch fence).
- **UDP از داخل تانل:** رله‌ی UDP ASSOCIATE (RFC 1928) — پورت ۵۳ محلی جواب می‌گیرد و بقیه‌ی ترافیک UDP از مسیر CONNECT-UDP احراز هویت‌شده (فعلاً WARP، هنگام فعال بودنش) می‌گذرد؛ fallback مستقیم UDP وجود ندارد. دیتاگرام‌های تکه‌تکه (FRAG≠0) دور ریخته می‌شوند و هر تلاش قدیمی فوراً کنار می‌رود. بیشینه‌ی جریان‌ها، حافظه‌ی صف و وینگ کشو همه محدود شده‌اند.
- **اندازه‌گیری داده:** شمارنده‌های native TUN هر ثانیه خوانده می‌شوند، روی reset شمارنده هم‌پایه‌گذاری می‌شوند و به همان مجموع‌های down/up صفحه‌ی وضعیت خوراک می‌دهند.
- **تست‌ها:** تست رله (DNS محلی، مسیر رله، تلاش قدیمی، بسته‌های تکه‌تکه و مذاکره‌ی کامل socks5)، استرس ۵۰-چرخه‌ای epoch برای پل DNS، و مهاجرت کامل تست‌ها از پشته‌ی قدیمی.
- **پرزلین:** مسیر native تازه است و به اعتبارسنجی روی دستگاه فیزیکی نیاز دارد؛ اتوماسیون حساب WebView ادعا نمی‌شود.

## English

- Native tunnel engine: the hand-rolled packet stack is retired; hev-socks5-tunnel 2.20.0 (vendored lwIP, NDK r27) now terminates the TUN device and every TCP/UDP flow. When the tunnel or relay is down nothing leaves the device directly — drops are silent and fail-closed.
- Anti-censorship DNS preserved on the native path: port-53 queries are answered locally with the DoH race, custom profiles, BlockAds, TTL patching and anti-poison rules. All of it moved into FoxDnsBridge with the epoch fence, so an answer minted by a stale transport attempt is never published or learned.
- UDP ASSOCIATE (RFC 1928): port 53 is answered locally; all other UDP traffic relays through the authenticated CONNECT-UDP path (currently WARP, when enabled). There is deliberately no direct-UDP fallback — unreachable relay means drop. Fragmented (FRAG != 0) datagrams are dropped, stale attempts are dropped, and flow count, queued bytes and associations are all bounded.
- Metering: native TUN counters are polled once a second, re-baselined on counter resets, and feed the same down/up totals the status screen already shows.
- Tests: relay coverage (local DNS path, relay path, stale attempts, fragmented datagrams, full socks5 negotiation), a 50-iteration epoch-fence stress test for the DNS bridge, and full test migration off the retired stack.
- Still a prerelease: the native path needs physical-device validation; WebView account automation is not claimed.
