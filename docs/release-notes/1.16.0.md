# Gozar 1.16.0

## فارسی

- **کرش رفع شد:** خطای `ConnectException` روی `raw.githubusercontent.com` (سم‌پاشی DNS فیلترینگ) دیگر برنامه را نمی‌کشد؛ زنجیره mirror امضادار + محافظ ضدکرش روی همه نخ‌های شبکه.
- **حجم مصرفی برمی‌گردد:** زنجیره HEAD→GET برای سهمیه، پرسش مجدد وقتی هدرها کم‌اند، و حافظه‌ی آخرین مقدار خوب به‌جای «نامشخص».
- **مغز خودتنظیم اتصال (بدون هیچ تنظیمی):** شناسایی سم‌پاشی DNS، حافظه‌ی آدرس سالم هر هاست زیر پین‌های SPKI، تقسیم ClientHello برای عبور از DPI مخرب، و یادگیری per-host حالت برنده با قرنطینه و بازآزمایی دوره‌ای — در هر دو هسته.
- **پایداری تانل:** نشست‌های H2 دسکتاپ keepalive واقعی گرفتند (مرگ خاموش = خطا و بازسازی، نه هنگ)؛ اندروید با PING دوره‌ای مسیر مرده را پیش از گیر کردن جریان بعدی کشف و بازسازی می‌کند.
- **UI دسکتاپ با assetهای واقعی Windscribe:** بج‌های اتصال و آیکون‌های شبکه‌ی خود Windscribe (GPL-2.0، کپی لایسنس داخل اپ و کردیت در README).

## English

- Crash fixed: the poisoned `raw.githubusercontent.com` answer (filtering DNS sinkhole) can no longer kill the app; signed mirror chain plus anti-crash guards on every network thread.
- Usage returns: HEAD→GET quota chain, a re-probe when headers are stripped, and last-known-good memory instead of "unavailable".
- Self-tuning reachability brain (zero settings): DNS-poisoning detection, per-host remembered addresses under SPKI pins, ClientHello segmentation against hostile middleboxes, per-host mode learning with quarantine and periodic re-probing - in both cores.
- Tunnel stability: desktop H2 sessions gained real HTTP/2 keepalive (silent death becomes an error and a rebuild, not a hang); Android probes idle sessions with H2 PINGs and rebuilds dead paths before the next flow stalls.
- Desktop UI now ships Windscribe's own vector badges and network glyphs (GPL-2.0; license copy bundled, credited in README).
