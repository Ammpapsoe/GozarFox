## Gozar 1.12.0-rc.1 — چرخش امن obfs4 و WebTunnel

**این نسخه Prerelease و مخصوص تست روی گوشی و شبکه‌های همراه اول و ایرانسل است؛ Stable نیست.** نسخهٔ 1.11.5 برای مسیر تست جدید منسوخ اعلام می‌شود. نصب این prerelease با همان هویت امضای جدید 1.11.5 انجام می‌شود، اما روی APKهای قدیمی‌تر با certificate متفاوت ابتدا uninstall لازم است.

### اتصال Bridge-first

- ترتیب جدید: Bridge دستی obfs4، سپس obfs4های فید امضاشده، سپس WebTunnel، و فقط در انتها Snowflake و Meek. Direct Tor دیگر در مسیر ورود اول قرار ندارد.
- هر obfs4 یا WebTunnel حداکثر ۱۵ ثانیه فرصت bootstrap و بررسی دسترسی Mozilla دارد. پاسخ قطعی connection refused یا connection reset باعث خروج سریع از همان attempt می‌شود؛ progress و خطاهای غیرقطعی فرصت کامل را حفظ می‌کنند.
- حداکثر ۱۰ Bridge خودکار و deadline مشترک ۱۵۰ ثانیه برای بخش rotation اعمال می‌شود. بعد از هر شکست، process جداگانهٔ Tor، IPtProxy، Control Socket، listener و state موقت پاک‌سازی می‌شوند.

### فید روزانه و امضا

- GitHub Actions هر ۲۴ ساعت منبع رسمی Tor MOAT builtin و دو فهرست community مستقل را ادغام، فیلتر و deduplicate می‌کند.
- فقط obfs4 و WebTunnel با endpoint عمومی IPv4، fingerprint و پارامترهای معتبر پذیرفته می‌شوند. IP خصوصی، loopback، آدرس مستند، URL ناامن و خط تزریقی حذف می‌شوند.
- فایل `packaging/bridges.json` با کلید جداگانهٔ Ed25519 امضا و همراه `bridges.json.sig` روی شاخهٔ `bridge-feed` منتشر می‌شود. کلید خصوصی فقط در Actions Secret است و کلید عمومی در اپ pin شده است.
- اپ پیش از استفاده، امضا، schema، زمان انقضا و تمام خطوط را بررسی می‌کند. فید نامعتبر یا منقضی کاملاً دور ریخته می‌شود. امضا اصالت انتشار را ثابت می‌کند، نه تضمین دسترسی یا بی‌خطربودن هر Bridge؛ موفقیت واقعی با bootstrap و Mozilla سنجیده می‌شود.

### Bridge دستی و حریم خصوصی

- صفحهٔ ورود و ثبت‌نام فیلد obfs4 و راهنمای رسمی `@GetBridgesBot` دارد. ورودی sanitize و فقط یک خط کامل obfs4 با IP عمومی پذیرفته می‌شود.
- Bridge دستی و فهرست دریافتی فقط در RAM هستند؛ در SharedPreferences، saved-state، cache یا لاگ ذخیره نمی‌شوند. Autofill برای فیلد غیرفعال است.
- Bridge در `torrc` یا فایل لاگ نوشته نمی‌شود. Tor با `DisableNetwork 1` شروع می‌شود و Bridge فقط از Control Socket اعمال می‌شود. تشخیص خطا فقط نوع transport، مرحله و درصد است و پیام خام حاوی Bridge یا IP منتشر نمی‌شود.

### تست و محدودیت

- تست‌های واحد برای امضا، انقضا، تزریق، IP غیرعمومی، سقف ۱۰ attempt، ترتیب fallback، timeout پانزده‌ثانیه‌ای و refusal/reset اضافه شده‌اند.
- تست native روی emulator روت‌شدهٔ GitHub Actions با SELinux آزمایشی Permissive و تست واقعی login/signup روی همین commit اجرا می‌شود؛ اطلاعات حساب فقط در Secrets باقی می‌ماند.
- هیچ ادعای تست گوشی فیزیکی، همراه اول یا ایرانسل قبل از دریافت نتیجهٔ کاربر وجود ندارد. این APK برای همان ارزیابی واقعی منتشر می‌شود.

## English

Gozar 1.12.0-rc.1 is a prerelease for physical-device testing on MCI and Irancell. It introduces manual obfs4 input, signed daily obfs4/WebTunnel rotation, fast rejection only on explicit refusal/reset, a 15-second per-bridge budget and a shared 150-second rotation deadline. Snowflake and Meek are last-resort fallbacks.

The signed feed combines Tor's official MOAT builtin source with two independent community sources. Invalid, private, loopback, expired, unsigned and injection-shaped entries are rejected. Manual and downloaded bridges remain in RAM only, are excluded from saved-state/autofill, and are applied through Tor's control socket rather than written to torrc or log files.

This build does not claim successful physical-device or Iranian-ISP validation. Native lifecycle and real-account tests run on the authorized rooted GitHub Actions emulator; the user's device and carrier tests remain the release gate for any later Stable version.
