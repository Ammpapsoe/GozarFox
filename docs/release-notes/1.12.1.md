## Gozar 1.12.1 — Apps Script برای ورود و دریافت Pass

**این نسخه Prerelease است، نه Stable.**

- Tor، Orbot، IPtProxy، Bridge و وابستگی‌های native مربوط به آن‌ها از Android حذف شده‌اند.
- صفحهٔ ورود به گرافیک سادهٔ پیش از Tor با پس‌زمینهٔ Firefox بازگشته است؛ دکمهٔ Stop، فیلد Bridge و Log Viewer مربوط به Tor وجود ندارند.
- Google Apps Script رلهٔ اصلی control-plane برای ورود، ساخت حساب، تبادل token، دریافت Pass و فهرست سرور است. ترافیک VPN از این رله عبور نمی‌کند.
- رله فقط مسیرهای ثابت Mozilla را می‌پذیرد و Origin، Referer، Cookie و مقصد دلخواه forward نمی‌کند. اطلاعات حساب و token در Apps Script ثبت یا log نمی‌شوند.
- اعتبارسنجی انتشار فقط شامل ورود حساب موجود با دریافت Pass و ساخت حساب آزمایشی تا مرحلهٔ `SIGNUP_CODE_REQUIRED` است؛ تست tunnel یا چرخهٔ native انجام نمی‌شود.

## English

This prerelease removes Tor and its native dependencies, restores the earlier simple Firefox login artwork, and uses a restricted Google Apps Script relay for Mozilla account and Guardian control-plane requests only. VPN traffic does not pass through Apps Script. Release validation is limited to existing-account login with Pass acquisition and test signup through code delivery.
