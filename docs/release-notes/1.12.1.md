## Gozar 1.12.1 — Apps Script برای ورود و دریافت Pass

**این نسخه Prerelease است، نه Stable.**

- Tor، Orbot، IPtProxy، Bridge و وابستگی‌های native مربوط به آن‌ها از Android حذف شده‌اند.
- صفحهٔ ورود به گرافیک سادهٔ پیش از Tor با پس‌زمینهٔ Firefox بازگشته است؛ دکمهٔ Stop، فیلد Bridge و Log Viewer مربوط به Tor وجود ندارند.
- ورود و ساخت حساب در WebView رسمی Mozilla با PKCE و اعتبارسنجی `state` انجام می‌شود؛ مسیرهای `account/login` و `account/create` از کلاینت و Apps Script حذف شده‌اند.
- تبادل code ابتدا از Apps Script تلاش می‌کند و فقط روی 406 از OAuth مستقیم استفاده می‌کند. دریافت Pass و فهرست سرور از Apps Script است و ترافیک VPN از این رله عبور نمی‌کند.
- رله فقط مسیرهای ثابت Mozilla را می‌پذیرد و Origin، Referer، Cookie و مقصد دلخواه forward نمی‌کند. اطلاعات حساب و token در Apps Script ثبت یا log نمی‌شوند.
- پس از دریافت Pass، درخواست اتصال تونل به‌صورت خودکار آغاز می‌شود؛ تأیید اولیهٔ VPN همچنان توسط dialog سیستم‌عامل Android کنترل می‌شود.

## English

This prerelease removes Tor and its native dependencies, restores the earlier simple Firefox login artwork, and moves account sign-in and sign-up to Mozilla's official WebView flow with PKCE and strict callback state validation. The removed password API routes are no longer available in the client or Apps Script. Code exchange tries Apps Script first and uses direct OAuth only after HTTP 406; Pass acquisition remains on Apps Script and VPN traffic never uses that relay. Tunnel startup is requested automatically after a Pass is stored, subject to Android's first-time VPN consent.
