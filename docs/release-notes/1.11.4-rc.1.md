## Gozar 1.11.4-rc.1 — پیش‌انتشار برای آزمایش / Pre-release for testing

**این نسخه پایدار نیست.** فقط برای آزمایش روی تلفن و رایانه است. Do not use for sensitive traffic.

### تغییرات / Changes
* فهرست سرورهای عمومی Mozilla به‌صورت رمزگذاری‌شده و حداکثر ۲۴ ساعته ذخیره می‌شود؛ نسخهٔ منقضی یا خراب استفاده نمی‌شود.
  The official Mozilla server list is cached encrypted for at most 24 hours; expired or corrupt copies are never used.
* اگر نسخهٔ ذخیره‌شدهٔ فهرست با خطای معمولی روبه‌رو شود، یک بار فهرست تازهٔ رسمی گرفته می‌شود. رد شدن از سوی رله (مثل 451) این کار را نمی‌کند.
  If a cached list fails with an ordinary error, one fresh official fetch is attempted. Relay refusals (such as 451) are not retried.
* فهرست در حین اتصال از داخل تونل بررسی و تازه می‌شود؛ در خطا، فهرست قبلی حفظ می‌شود.
* دامنهٔ فهرست مسیرهای مستقیم (`packaging/ir-domains.txt`) با امضای Ed25519 جدا محافظت می‌شود. تا ادغام در `main` از نسخهٔ داخلی استفاده می‌شود.

### محدودیت‌های شناخته‌شده / Known limits
* بازیابی واقعی از خطای 451 روی شبکهٔ کاربر هنوز تأیید نشده است.
* ثبت‌نام واقعی تا مرحلهٔ ایجاد حساب تست شده است؛ تأیید ایمیل و استفاده از پاس تحت این نسخه تأیید نشده‌اند.
* پیشنهاد می‌شود از حساب اصلی خود استفاده نکنید.
