# Gozar 1.18.3 — پیش‌نویس اعتبارسنجی

این پیش‌نویس منتشر نشده و آمادهٔ Stable نیست. شمارهٔ نسخه برای ساخت و بررسی بسته‌های نامزد انتشار در نظر گرفته شده است.

## تغییرات قابل توجه

- در مسیر TUN ویندوز، RACK در پشتهٔ TCP غیرفعال شده است. در آزمون محلی Wintun روی GitHub Actions، تنظیم قبلی هنگام دانلود متوقف شد و پنج تکرار با تنظیم جدید تکمیل شدند. این آزمون سرعت اینترنت یا عملکرد روی relay واقعی را نشان نمی‌دهد.
- در مسیر HTTP/2 تغییراتی در بافرها و پنجرهٔ دریافت اعمال شده است؛ اثر آنها بر شبکه‌های واقعی و دستگاه‌های مختلف هنوز نیازمند اندازه‌گیری است.
- دستورات و آدرس‌های مخزن به `github.com/Ammpapsoe/GozarFox` مهاجرت داده شده‌اند. بعضی تگ‌ها و فایل‌های تاریخی به مخزن جدید منتقل نشده‌اند؛ بستهٔ منبع OpenWrt هنوز به یک تگ قدیمیِ موجودنبودنی اشاره می‌کند.
- اجزای آزمایشی FakeDNS و مدیریت تنظیمات پراکسی هنوز فعال نیستند و نباید به عنوان امکانات کامل این نسخه معرفی شوند.

## موارد باز پیش از انتشار

- ساخت و اعتبارسنجی امضای بسته‌ها و تست‌های GitHub Actions برای **همین کامیت نسخه** باید تکمیل شود.
- ورود حساب، ارتقای APK تاریخی، عملکرد روی گوشی واقعی و عملکرد روی اینترنت و شبکه‌های دارای تأخیر و packet loss هنوز برای این نسخه تأیید نشده‌اند.
- مقایسهٔ کارایی همسان با رقیب برای ویندوز و اندروید هنوز انجام نشده است؛ ادعای برتری یا بی‌نقص‌بودن مجاز نیست.
- حفاظت DNS ویندوز در حضور چند رابط شبکه به بررسی و تست مستقل نیاز دارد. ممکن است رفتار آن با محافظت WFP رقیب متفاوت باشد؛ نشت در این بررسی اثبات نشده است.
