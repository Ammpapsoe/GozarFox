## Gozar 1.11.5-rc.1 — تشخیص Tor روی گوشی واقعی / Physical-device Tor diagnostics

**این نسخه Stable نیست.** تست کاربر روی گوشی واقعی در ورود دوم شکست خورده است. این پیش‌انتشار فقط برای تکرار همان تست و بررسی اصلاح lifecycle است؛ برای ترافیک حساس استفاده نشود.

### علت‌های قطعیِ پیداشده در کد / Confirmed code defects

- پوشهٔ `TorService` هنگام cleanup حذف می‌شد، اما کتابخانه مسیر آن را static نگه می‌دارد. تلاش بعدی `torrc` را بدون ساختن دوبارهٔ پوشه می‌نوشت و خطا پنهان می‌شد. اکنون پوشه قبل از هر راه‌اندازی دوباره ساخته می‌شود.
- خاموش‌شدن Tor و IPtProxy بین تلاش‌ها asynchronous است. اکنون قبل از `unbind` و شروع تلاش بعدی، سیگنال توقف Tor و بسته‌شدن SOCKS بررسی می‌شود.
- خطاهای Direct، Snowflake و Meek دور ریخته می‌شدند و لاگ Tor به `/dev/null` می‌رفت. اکنون خطای واقعی، آخرین bootstrap و انتهای لاگ `notice` با `SafeLogging 1` در logcat و پیام خطای ورود ظاهر می‌شود؛ رمز، توکن یا محتوای حساب ثبت نمی‌شود.

### تغییرات قابل مشاهده / Visible changes

- هر transport حداکثر ۹۰ ثانیه برای bootstrap کامل صبر می‌کند و درصد و مرحله را روی صفحهٔ ورود نشان می‌دهد.
- پیام پیش‌فرض انگلیسی به `Establishing a secure connection…` اصلاح شده است.
- تست instrumentation دو چرخهٔ کامل راه‌اندازی و توقف را برای تشخیص خرابی ورود دوم انجام می‌دهد؛ اجرای native همچنان gate خودکار انتشار نیست.

### محدودیت / Remaining gate

موفقیت compile، unit test یا bootstrap مصنوعی اثبات رفع مشکل روی گوشی نیست. Stable فقط پس از دو ورود متوالی موفق روی دستگاه واقعی، توقف Tor پس از ورود و برقراری تونل مستقیم Mozilla قابل انتشار است.
