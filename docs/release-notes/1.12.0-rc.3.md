## Gozar 1.12.0-rc.3 — پایداری Tor و چرخهٔ اتصال

**این نسخه Prerelease و مخصوص تست روی گوشی واقعی همراه اول و ایرانسل است؛ Stable نیست.** هیچ نتیجه‌ای از emulator به‌عنوان تأیید اپراتور ایرانی تلقی نمی‌شود. نصب با هویت امضای جاری انجام می‌شود و APKهایی با certificate قدیمی با این هویت سازگار نیستند.

### اصلاح چرخهٔ bootstrap و مالکیت تونل

- تا پیش از ۷۵٪، بودجهٔ قبلی rotation حفظ می‌شود. پس از عبور از ۷۵٪، Bridge عوض نمی‌شود و Tor یک مهلت ثابت ۳۰ ثانیه‌ای برای تکمیل مدار تا ۱۰۰٪ دارد.
- رسیدن به ۱۰۰٪ پایان rotation است. خطا یا timeout درخواست Mozilla دیگر باعث بستن Tor و مصرف Bridge بعدی نمی‌شود؛ retry روی همان SOCKS انجام می‌شود.
- تونل پس از خطای login، انتظار کد و تلاش مجدد Pass زنده می‌ماند. cleanup کامل فقط با Stop، Logout یا دریافت و ذخیرهٔ موفق Pass انجام می‌شود.
- دکمهٔ Stop در صفحهٔ ورود و ثبت‌نام اضافه شده است. راهنمای فارسی و انگلیسی نیز احتمال انتظار تا یک دقیقه را توضیح می‌دهد.

### اصلاح lifecycle سرویس اختصاصی Tor

- سرویس `:tor` در مدت اتصال foreground است و اعلان کم‌اهمیت بدون جزئیات شبکه دارد.
- مرگ process با Binder death recipient تشخیص داده می‌شود و bind در همان زمان شکست می‌خورد، نه پس از انتظار کامل.
- PID سرویس از Binder محلی خوانده می‌شود. cleanup با `/proc` و ActivityManager مرگ process قبلی را بررسی می‌کند و تلاش بعدی تا پایان قطعی cleanup شروع نمی‌شود.
- تشخیص نادرست `bridge=false` حذف شده است. مقدار Bridge از `GETCONF` خوانده یا لاگ نمی‌شود؛ پذیرش SETCONF و مرحلهٔ bootstrap معیار وضعیت است.
- listenerهای SOCKS و IPtProxy، Control Socket، state موقت و process اختصاصی پیش از attempt بعدی پاک‌سازی می‌شوند.

### Bridge و حجم بسته

- دو نمونهٔ obfs4 گزارش‌شده با certificate استاندارد ۷۰ کاراکتری به regression tests اضافه شده‌اند. whitespace مجاز در کپی پیام به شکل امن normalize می‌شود، اما چند Bridge، کاراکتر کنترلی مخرب، injection و IP غیرعمومی همچنان رد می‌شوند.
- Bridgeها فقط در RAM و از Control Socket اعمال می‌شوند و در torrc، preferences، saved-state یا لاگ نوشته نمی‌شوند.
- کتابخانه‌های native در APK فشرده می‌شوند و Build برای هر ABI سقف ۲۵ مگابایت و فشرده‌بودن فایل‌های `.so` را اجبار می‌کند. هیچ transport یا ABI فیزیکی لازم برای تست حذف نشده است.

### اعتبارسنجی و محدودیت

- تست‌های واحد برای مهلت ۳۰ ثانیه‌ای مرحلهٔ پایانی، حفظ تونل پس از خطا، retry فقط HTTP، Stop همزمان، cleanup پیش از شروع بعدی، نمونه‌های obfs4 و موفقیت/شکست Pass اضافه یا به‌روز شده‌اند.
- تست native و login/signup واقعی روی emulator روت‌شدهٔ GitHub Actions با SELinux آزمایشی Permissive اجرا می‌شود؛ اطلاعات حساب فقط در Secrets می‌ماند.
- موفقیت نهایی روی همراه اول و ایرانسل باید با همین APK روی گوشی فیزیکی سنجیده شود و برای Stable بعدی لازم است.

## English

Gozar 1.12.0-rc.3 is a prerelease for physical-device testing on MCI and Irancell. It freezes bridge rotation after 75% bootstrap, grants one fixed 30-second circuit-completion window, retains a fully bootstrapped Tor tunnel across Mozilla/account retries, and cleans up only on Stop, logout or successful pass acquisition.

The isolated Tor service now has foreground ownership, Binder death detection, verified PID cleanup and a strict barrier against starting another attempt before the previous process has died. The misleading bridge boolean was removed without reading or logging sensitive bridge configuration.

Reported standard obfs4 samples are covered by regression tests. Native libraries are compressed, with a mandatory 25 MiB per-ABI release size check. Emulator validation does not establish compatibility with Iranian carriers; physical-device results remain required before any Stable release.
