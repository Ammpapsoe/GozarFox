EXPERIMENTAL DEVELOPMENT BUILD — NOT A RELEASE

This build uses the REAL Gozar core and the existing Flutter login. It contains
only a limited subset of the original Qt UI and test backend compatibility
shims. It is not the complete Windscribe desktop application. Real login,
connection, network cleanup, upgrade and crash recovery have not been verified
for this integration. It is unsigned or only ad-hoc signed. Its licences and
assets have not received final distribution review.

Use only for an owner's deliberate manual evaluation. It can change network
routes and proxy settings and reads the existing Gozar account/configuration.
On Windows the preview install is separate, but its account/configuration is not.
Microsoft Edge WebView2 Runtime may be required for embedded sign-in.
Before opening it, quit all other Gozar instances; there is no system-wide
single-owner guarantee. Do not install over an existing working installation,
do not redistribute it as a finished product, and have a way to restore your
network settings. No credentials are included in this package.
